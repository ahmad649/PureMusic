# Audio Samples

This folder contains sample audio outputs generated by the Vocal Isolation project.

## Directory Structure

```text
samples/
└── output_samples/
    ├── Drums.wav
    ├── Drums_hat.wav
    ├── Vocals.wav
    └── Vocals_hat.wav
```

## Description

The audio files included in this folder demonstrate the performance of the source separation pipeline:

* **Drums.wav** – Extracted drum stem.
* **Drums_hat.wav** – Drum stem after processing.
* **Vocals.wav** – Isolated vocal stem.
* **Vocals_hat.wav** – Vocal stem after processing.

## Note

To keep the Jupyter notebook lightweight and compatible with GitHub's file size limits, embedded audio playback outputs were removed from the notebook. These sample files are provided separately so that results can still be evaluated and compared.

Users can listen to these files directly to assess the quality of the source separation and vocal isolation process.
