# PureMusic

**PureMusic** is a deep learning-based project aimed at isolating vocals from music tracks. By utilizing state-of-the-art techniques in audio signal processing, this tool enables the separation of vocals from the instrumental components of a song. It can be used for a wide range of applications such as remixing, karaoke systems, music analysis, and audio restoration.

## Key Features:
- **Vocal Isolation:** Accurately isolates vocals from music tracks using advanced deep learning models.
- **High Performance:** Utilizes cutting-edge methods in source separation to achieve high-quality results.
- **Easy to Use:** Includes user-friendly scripts for data processing, training, and evaluation of the model.

## Project Overview:
Vocal isolation is a challenging task in the field of audio processing, and **PureMusic** aims to tackle it using modern neural network architectures. The project uses high-quality datasets like **MUSDB18** and **MedleyDB** that provide pre-isolated stems for training the model.

### Datasets:
- **MUSDB18:** A comprehensive dataset with 150 full-length tracks across various genres, including isolated vocals and instrumentals.
- **MedleyDB:** A smaller, high-quality dataset for testing and validating vocal separation models.
